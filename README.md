# 236522_LuuMinhNhat

## 1. Giới thiệu đề tài
Xây dựng ứng dụng quản lý sinh viên nhằm hỗ trợ lưu trữ, tra cứu và quản lý thông tin sinh viên thông qua giao diện web.

## 2. Công nghệ sử dụng
- Frontend: HTML, CSS, JavaScript hoặc React.js.
- Backend: Node.js, Express.js.
- Cơ sở dữ liệu: MongoDB.
- ODM: Mongoose.
- Quản lý mã nguồn: Git và GitHub.

## 3. Chức năng chính
- Hiển thị danh sách sinh viên.
- Thêm sinh viên mới.
- Cập nhật thông tin sinh viên.
- Xóa sinh viên.
- Tìm kiếm thông tin sinh viên.

## 4. Cấu trúc dự án
```text
236522_LuuMinhNhat/
├── frontend/
├── backend/
├── docs/
├── README.md
└── .gitignore
```

## 5. Yêu cầu cài đặt
- Node.js và npm.
- MongoDB hoặc MongoDB Atlas.
- Visual Studio Code.
- Trình duyệt web.

## 6. Hướng dẫn cài đặt
1. Clone repository từ GitHub.
2. Cài đặt Node.js và npm.
3. Cài đặt các thư viện cần thiết cho backend bằng lệnh `npm install`.
4. Cấu hình biến môi trường trong tệp `.env` ở máy cá nhân.
5. Khởi động backend và frontend theo cấu hình của dự án.

## 7. Bảo mật
- Không đưa mật khẩu lên GitHub.
- Không công khai access token.
- Không đưa thông tin kết nối cơ sở dữ liệu bí mật lên GitHub.
- Sử dụng `.gitignore` để loại trừ tệp `.env` và `node_modules/`.

## 8. Quản lý mã nguồn
Sử dụng Git để quản lý phiên bản và GitHub để lưu trữ, chia sẻ mã nguồn dự án.
## 3. Cấu trúc dự án

```text
236522_LuuMinhNhat/
├── frontend/
│   └── index.html
├── backend/
│   ├── package.json
│   └── server.js
├── .gitignore
└── README.md
```

## 4. Yêu cầu cài đặt

- Node.js và npm.
- Trình duyệt web như Google Chrome hoặc Microsoft Edge.
- Git và tài khoản GitHub nếu muốn tải mã nguồn về máy.

## 5. Hướng dẫn chạy chương trình

### Frontend

Mở tệp `frontend/index.html` bằng trình duyệt web.

### Backend

Mở Terminal tại thư mục `backend`, sau đó chạy:

```bash
npm install
npm start
```

Lưu ý: Backend cần có mã nguồn trong `server.js` trước khi chạy.

## 6. Quản lý mã nguồn

Mã nguồn được lưu trữ trên GitHub. Các thay đổi được ghi nhận thông qua commit để thuận tiện theo dõi lịch sử phát triển dự án.
